# 신입 100일 생존기

> AI가 알려주지 않는 '우리 회사'의 암묵지를 전수하는 신입사원 온보딩 웹 플랫폼
> 교육공학 프로젝트 · 에듀링크 (김용은 · 오승현 · 육예원)

가상 기업 **㈱하이브릿지(가칭) 인사팀**의 신입사원이 되어, 2D 사무실을 돌아다니며 선배들의 실제 경험으로 만든 상황 카드에 대응하는 시뮬레이션 게임과 직원 간 소통 공간을 결합한 프로토타입입니다.

## 실행 방법

설치가 필요 없습니다. `index.html`을 브라우저에서 열면 됩니다.

- 이동: 방향키 / WASD (모바일은 화면 터치 패드)
- 말 걸기 · 대화 넘기기: Space / Enter
- 선택지: 1 · 2 · 3

## 주요 기능

| 사용자 | 기능 |
|---|---|
| 신입사원 | 캐릭터 생성 → 5일(D+1~D+100) × 하루 3개 상황 카드 → 4대 게이지(팀장 신뢰 · 동료 관계 · 업무 성과 · 체력) → 다중 시니어 피드백 → 퇴근 회고 → 100일 성장 유형 엔딩 |
| 소통 공간 | 동기방 · 선배에게 묻기 · 팀장 라운지 · 익명 질문방, 게임 중 '선배에게 물어보기' 연결, 좋은 질문을 상황 카드 후보로 제안 |
| 시니어 | 4가지 질문(5분 템플릿)으로 경험 등록 → 자동으로 상황 카드 생성, 기여 배지 · 학습한 신입 수 |
| HRD 담당자 | 카드별 선택 분포, 자주 막히는 상황, 엔딩 분포, 카드 활성/비활성 관리 |

## 파일 구조

```
index.html        진입점
css/style.css     스타일
js/data.js        콘텐츠 (상황 카드 · 시니어 · 회고 · 엔딩) ← 조사 결과로 교체
js/game.js        2D 사무실 게임 (맵 · 캐릭터 · 대화 · 퀘스트)
js/app.js         화면 전환 · 소통 공간 · 시니어 · HRD 대시보드
```

## 참고

- 현재 상황 카드와 시니어 피드백은 기획안을 바탕으로 작성한 **예시 콘텐츠**이며, 인터뷰 · 설문 결과로 교체 예정입니다.
- 소통 공간의 선배 자동 답변과 HRD 대시보드의 일부 수치는 **시연용 데이터**입니다.
- 데이터는 서버 없이 브라우저 localStorage에 저장됩니다.
